# Reference data

`original_reference.json` records the earlier double-precision script, including
its rounded absolute temperatures. It is a historical compatibility fixture.

`ising_reference_high_precision.json` is the canonical high-precision fixture
for the Uni20 HOTRG comparison: widths 2, 4, ..., 256 at exact reduced
temperatures `T/Tc = 1/1` and `6/5`, with the lowest `min(24, 2**sites)` scaling
dimensions in each case (328 values total). Each list includes degeneracies
and starts with the ground state's exact zero. These are the finite-width
values, not their conformal limits.

Nonzero values are decimal strings with **100 significant digits**, not JSON
numbers. Temperatures are exact rational strings, not rounded absolute Tc
values. Parse each value directly into the destination scalar at its chosen
precision; do not convert through a double. One file supplies double, extended,
quadruple and arbitrary-precision consumers. It supplies only 100 digits:
calculations needing more reference digits must regenerate with higher settings.

The file records the observable, ordering, output precision and generation
settings. It is generated with `levels_reduced` at 140 decimal working digits,
then regenerated at 180 digits. Every published string must agree before the
script writes the file. From the repository root, with the `precision` extra:

```bash
python scripts/generate_ising_reference.py --check
python scripts/generate_ising_reference.py
```

`--check` verifies the existing file without rewriting it; the second command
regenerates it. The script also works when invoked by absolute path from another
directory. The script and data are versioned together in Git.

This is a frozen regression fixture generated by the implementation, with a
precision-convergence check. The independent Boltzmann-matrix tests remain the
check of the physical formula. `tests/test_reference_data.py` consumes the
stored strings in double precision and at 25, 50 and 100 working digits, and
runs `--check` to verify all 100 published digits.
